# Architecture Decision Records (ADRs)

### ADR-001: Use TypeScript/Node.js ESM for Orbit CLI & Context Engine
**Status**: ACCEPTED  
**Rationale**: Provides fast cross-platform execution on Windows, macOS, and Linux without native binary compilation dependencies.

### ADR-002: Selective ECC Skill Provisioning Model
**Status**: ACCEPTED  
**Rationale**: Avoids context window clutter by provisioning only relevant domain & quality skills into .agents/skills/.

### ADR-003: Operating Contract in .agents/rules/orbit-project.md
**Status**: ACCEPTED  
**Rationale**: Enforces autonomous execution, intent inference, and verification protocol natively within Antigravity IDE.
